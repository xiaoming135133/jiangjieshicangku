# datasets　可提交的标注与清单

照片不进仓库（在 `data/photos/`，`.gitignore` 已拦），**这里只放假得下、比得了的东西**。

| 文件 | 状态 | 内容 | 谁维护 |
| --- | --- | --- | --- |
| `photos.csv` | 待建 | D1 照片清单：编号、文件名、分层、拍摄日期、来源课程 | 数据负责人 |
| `align.csv` | 待建 | D2 对齐标注 200 条（列定义见 [`../docs/06`](../docs/06-评测集与指标.md) §4.3） | 标注两人 + 队长仲裁 |

建文件时按 `docs/06` 给出的列头建，不要自己加中文列名——脚本要读它。

约定：

- 一行一条，不合并单元格，不用 Excel 另存为（Excel 可能改编码）。
- 用 UTF-8，逗号分隔；字段内有逗号就用双引号包起来。
- 人工列（`label_*`）永不被脚本覆盖，模型结果另起 `pred_*` 列。
- 每次实验在提交信息里写清：`test(data): D1 baseline 第 2 轮，换识别服务`
