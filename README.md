## 这是什么

理工科学生一学期会拍下两三百张板书。拍下来不难，难的在后面：**找不到、连不上、用不上**。
现有工具已经把「拍清楚、认出来、按模块归类」做到了商品级水准，我们不重复这一段，只做认完之后那一步——
把**一次性的整理**，变成**可持续维护的增量结构**。

每张新照片进来，系统只回答一个问题：**它该长在哪？** 有把握就直接挂上去并说明理由；没把握就说「我不知道」，
先放进未归类箱，等攒够几条一次性问你。你改过的每一处，都会改变它下次的判断。

完整方案见 [`docs/01-项目概述.md`](docs/01-项目概述.md) 与 [`docs/02-技术方案.md`](docs/02-技术方案.md)。

## 参与开发

```bash
git clone https://github.com/xiaoming135133/jiangjieshicangku.git   # 改名后地址会变成 .../loom，旧地址自动跳转
cd jiangjieshicangku
git switch -c feat/<模块>-<短描述>     # 不要直接改 main
# 改完：一次提交只做一件事，信息写清做了什么
git add -A && git commit -m "feat(align): 加入符号路候选召回"
git push -u origin HEAD                # 到网页开 PR，自己先看一遍 diff
```
