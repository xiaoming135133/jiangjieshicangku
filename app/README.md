## 建工程时的注意

- 用 Android Studio 新建工程后，先确认 `.gitignore` 生效：`build/`、`.idea/`、`local.properties`、`*.jks` 都不该出现在 `git status` 里。
- 包名建议 `com.jiangjieshi.loom`（不含院校信息）。
- 首版只做单门课程、三层树。跨课程连接在 W8 之后再谈。
- 所有网络结果都要能在断网时降级：已同步的节点本地可查可改（§2.3.7）。
