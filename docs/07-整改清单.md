
## 4. 一个需要你拍板的决策

**赛前把仓库设为 Private。**

- 好处：计划书、技术路线、指标都在网上挂着，等于提前把方案公开；如果有人照着做一遍，你很难证明先后。

- 操作：`Settings → General → Danger Zone → Change visibility → Make private`。
- 建议节奏：**现在转 Private，1 月 15 日提交后再转回 Public**，并在 README 里补一句「赛后开源」。
